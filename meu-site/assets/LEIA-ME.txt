==========================================================
 ASSETS FOLDER — how to add your images
==========================================================

Organize your files by category inside "assets".
If an image is missing, the site automatically shows a
gradient/emoji fallback (nothing breaks).

----------------------------------------------------------
1) assets/jogos/  → game covers (portrait, ideal 3:4)
   Current files:
      detroit.jpg, roblox.jpg, minecraft.webp,
      spiderman2.webp, undertale.png

2) assets/shows/  → favorite series & animes (portrait 3:4)
   Current files:
      breakingbad.jpg, dexter2006.jpg, tvd.jpg,
      chainsawman.jpg, jjk.jpg, kimetsu.jpg,
      pantyandstocking.jpg

3) assets/musicas/ → square song/album covers (1:1)
   Current files:
      letdown.jpg, nosurprises.jpg,
      motionpicturesoundtrack.jpg,
      tempoperdido.jpg, paisefilhos.jpg

4) assets/software/ → software logos (square, ideal 1:1)
   Current files: affinity.webp, photoshop.webp

5) assets/linguagens/ → language logos (square, ideal 1:1)
   Current file: luau.webp

6) Root of assets/ → special images
   mypfp.webp        → hero profile picture (Discord animated
                       overlay sits on top of it)
   nyancat.gif       → Nyan Cat above the "About Me" title
   goldenlocket.png  → locket above the "Besties" category

----------------------------------------------------------
TIPS
- Use exactly the same name (and extension) as in
  index.html — the name in the code points to the file.
- If you change the extension (e.g. .png instead of .jpg),
  update the src in index.html too.

----------------------------------------------------------
THE CAT (neko.js)
- neko.js comes from https://louisabraham.github.io/nekojs/
- It is loaded at the end of index.html with data-autostart.
- Remove that <script> tag if you don't want the cat.
